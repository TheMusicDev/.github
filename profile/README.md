# Accessible technology for independent music.

We build fast, affordable tools for indie musicians, studios, and venues — **without the enterprise price tag.**

Music software shouldn't require a label-sized budget. The good tools were built for enterprise; independent operators got stuck choosing between a half-built spreadsheet and software that costs more than their monthly revenue. We close that gap.

## Who we build for

| | | |
|---|---|---|
| 🎤 **Indie artists** | Tools for releasing, promoting, and getting paid | so you can focus on the art |
| 🎛️ **Studios** | Booking, session management, and client collaboration | all in one place |
| 🏟️ **Venues** | Ticketing, scheduling, and audience tools | built for how independent venues actually run |

## The setlist

Our current stack — played in order:

1. **TypeScript** — everything starts here
2. **React & Astro** — fast sites, faster apps
3. **Tailwind CSS** — styling without the fight
4. **PostgreSQL** — where the data lives
5. **Docker & CI/CD** — ships on time, every night

**Encore:** whatever your project needs. If the right tool doesn't exist, we build it — and you own it.

## How we work

- **Accessibility first** — usability beats power. Every tool starts with the person using it daily.
- **Fair & transparent** — clear scope and pricing, no lock-in. You own what we build for you.
- **Community-driven** — our clients are the reason we exist, not a target market.
